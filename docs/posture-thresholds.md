# 자세 판정 임계값

판정은 **온보딩에서 잡은 개인 기준값(baseline) 대비 상대값**으로 한다.
절대 각도를 쓰지 않는 이유: 사람마다, 모니터 높이마다 평소 각도가 다르다.

구현: `src/shared/posture.ts` (파라미터), `src/shared/posture-engine.ts` (판정)

## AI 팀과 맞춘 것

AI 레포 README 기준이다.

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 나쁜 자세 확정까지 유지 | 3초 | 양쪽 동일 |
| 복귀 대기 | 2초 | 양쪽 동일 |
| 진입/복귀 기준 분리 | 적용 | 기준선 근처에서 깜빡이는 것을 막음 |
| 거북목과 고개 숙임 | 구분하지 않고 하나의 "나쁜 자세" | AI 레포 ADR 0002 |
| 기준값 | 개인 기준(캘리브레이션) 대비 상대 비교 | 양쪽 동일 |

**아직 못 정한 것** (AI 레포: "데이터가 적어서 아직 상수는 조정하지 않았습니다")

- pitch 편차(도)
- size 배율 — AI 쪽은 pitch만 쓰고 size는 쓰지 않는다. 쓸지 말지부터 합의 필요
- severity MILD / MODERATE / SEVERE 구간
- 복귀 기준선(`exitScore`) 값

## 파라미터

| 이름 | 뜻 |
| --- | --- |
| `pitchDeltaDeg` | 기준보다 이만큼(도) 더 숙이면 나쁜 자세 후보 |
| `sizeRatio` | 기준보다 얼굴이 이 배율 이상 커지면(가까워지면) 나쁜 자세 후보 |
| `holdMs` | 이 시간 동안 이어져야 나쁜 자세로 **확정** |
| `recoverMs` | 이 시간 동안 바른 자세여야 **복귀** |
| `exitScore` | 복귀 기준선. 진입은 1.0, 복귀는 이 값 아래로 내려와야 인정 |
| `moderateFactor` / `severeFactor` | 기준 초과량이 이 배수를 넘으면 MODERATE / SEVERE |

pitch와 size 중 **더 많이 벗어난 쪽**을 쓴다.

## 민감도 프리셋

설정의 교정 강도 슬라이더 3단계와 이어진다.

| | 0 느슨하게 | 1 보통 (기본) | 2 엄격하게 |
| --- | --- | --- | --- |
| `pitchDeltaDeg` | 15 | 10 | 6 |
| `sizeRatio` | 1.20 | 1.14 | 1.08 |
| `holdMs` | 3000 | 3000 | 3000 |
| `recoverMs` | 2000 | 2000 | 2000 |
| `exitScore` | 0.8 | 0.8 | 0.8 |
| `moderateFactor` | 1.6 | 1.6 | 1.6 |
| `severeFactor` | 2.2 | 2.2 | 2.2 |

> 시간(3초·2초)과 구조는 AI 팀과 맞췄다.
> 각도·배율·severity 구간은 **FE 임시값**이다. 측정 데이터가 쌓이면 바꾼다.

## 판정 규칙

- 기준을 벗어난 상태가 `holdMs` 동안 이어져야 나쁜 자세로 확정한다.
- 확정되는 그 순간에만 `POSTURE_BAD` 를 **한 번** 보낸다. 계속 숙이고 있어도 늘지 않는다.
- 복귀는 `exitScore` 아래로 내려온 상태가 `recoverMs` 동안 이어져야 인정한다.
  진입(1.0)보다 낮게 둬서 기준선 근처에서 상태가 깜빡이지 않는다.
- 복귀한 뒤 다시 나빠지면 또 한 번 보낸다. 복귀 전에 잠깐 폈다 다시 숙이는 것은 세지 않는다.
- **얼굴이 보이지 않는 동안은 판정을 멈추고 상태를 비운다.** 자리 비움이 나쁜 자세로
  쌓이지 않고, 돌아오면 처음부터 다시 잰다.
- severity 는 확정될 때까지 **가장 심했던 정도**로 매긴다.

## 알려진 한계 (AI 레포 측정, v0.1.0 · 1인 60초 × 6개 라벨)

| 자세 | 나쁜 자세로 판정된 비율 |
| --- | --- |
| 바른 자세 | 4.2% |
| 거북목(머리 내밀기) | 77.5% |
| 고개 숙임 | 95.0% |

- 바른 자세 오탐은 **기준을 다시 잡지 않고 10~20cm 뒤로 앉은** 기록에서만 발생했다.
  앉는 거리가 바뀌면 각도 기준이 약 5도 이동한다 → 설정의 "기준 다시 잡기" 안내가 중요하다.
- 거북목·고개 숙임이 100%가 아닌 것은 3초 대기와 평균 처리 때문이다 (의도한 동작).
- 필기처럼 정상적인 짧은 숙임도 3초를 넘으면 알림이 간다. 유지 시간을 늘릴지는
  AI 레포의 숙임 구간 길이 분포(중앙값·p90) 분석 결과를 보고 정한다.

## 구현이 다른 점 (참고)

AI 레포는 MediaPipe **Face Detector**(BlazeFace)로 키포인트 6개에서 각도를 근사하고,
감지 주기를 1Hz / 4Hz / 0.33Hz 로 조절한다.
이 앱은 **Face Landmarker** 의 얼굴 변환 행렬에서 pitch 를 바로 얻고 15fps 로 돌린다.
전력 소모가 문제가 되면 AI 레포의 적응형 주기를 가져온다.

## 서버로 가는 것

`POSTURE_BAD` 이벤트의 `severity` 뿐이다.
pitch, size, 랜드마크, 기준값은 기기 밖으로 나가지 않는다.

MediaPipe 는 실행할 때 구글(`odml.pa.googleapis.com`)로 사용 기록을 보내려 한다.
영상이 아니라 사용 통계지만, detector 페이지의 CSP(`default-src 'self'`)가 이를 막는다.
끄는 설정이 없어서 CSP 로 막고, 콘솔 소음만 `windows.ts` 에서 걸러낸다.
